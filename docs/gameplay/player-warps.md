# Player Warps

Built something worth showing off? Player warps let you set your own public teleport point — free to create.

## Creating a warp

```
/pw create <name>
```

Aliases for the base command: `/playerwarp`, `/playerwarps`, `/pwarp`, `/pwarps`, `/axplayerwarps`, `/axpw`.

## Finding and visiting warps

```
/pw list
```

or open the browsable warp menu with `/pw` on its own — pick a category (building, shop, farm, PvP, event, fun, and more) and teleport straight there.

!!! tip "Free to create"
    Creating a player warp doesn't cost anything right now — go ahead and set one up for your base, shop, or project.
