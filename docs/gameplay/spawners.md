# Spawners

Mob spawners on ShinyVale store up mobs' drops and XP for you to collect, instead of you having to stand there killing mobs one at a time.

## Using a spawner

Right-click a placed spawner to open its menu — from there you can check its stored items, collect XP, and sell what it's produced.

## Breaking and moving a spawner

Break a spawner with a **Silk Touch pickaxe** (iron, golden, diamond, or netherite) to pick it up as an item you can move and re-place elsewhere.

## Stacking

Placing another spawner of the same mob type on top of/into an existing one merges them into a single stack instead of two separate spawners. A stacked spawner produces proportionally more — more mobs per cycle, more storage space, and a bigger XP cap — all from one block.

## Checking prices

```
/ss prices
```

Shows the sell price for everything spawners can drop, aliases `/smartspawner` and `/spawner`.
