# AFK Area

If you need to step away, ShinyVale has a dedicated AFK zone rather than leaving you exposed wherever you happen to be standing.

```
/warp afk
```

Head there when you're going idle — it's a safe area, and idling there earns you passive rewards over time just for being present.
