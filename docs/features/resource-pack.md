# Resource Pack

ShinyVale uses a custom resource pack to add its own textures, icons, and visual touches on top of vanilla Minecraft — things like custom menu icons and server branding you won't see anywhere else.

!!! warning "It's required, not optional"
    ShinyVale's pack is sent automatically when you join, and it's required to play properly. Some menus and items are built around it — without it, a handful of icons will look wrong or plain.

## Accepting the pack

When you join, Minecraft will prompt you to accept a server resource pack. Click **Yes**. If your client has "Server Resource Packs" set to disabled or prompt-only in your settings, switch it to **Enabled** so ShinyVale's pack can load automatically next time.

**Java Edition:** `Options → Resource Packs → Server Resource Packs: Enabled`
