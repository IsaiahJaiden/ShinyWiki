# Bedrock & Crossplay

ShinyVale supports Bedrock Edition players — console, mobile, and Windows Bedrock — alongside Java players on the same worlds.

## Connecting

Use the same server address as Java players, but Bedrock connects over its own port (**19132**) automatically if you're using a Bedrock client — you generally just need the address, not a special port entry, since most Bedrock clients handle this for you.

!!! info "Account linking"
    ShinyVale supports linking your Bedrock account to a Java-style identity for the best experience. If you run into a login issue as a Bedrock player, ask in the [Discord](https://discord.gg/G74PkPv2XQ) — this is the one area worth double-checking with staff directly, since exact requirements can vary.

## Resource pack

ShinyVale's [resource pack](resource-pack.md) is built for Java Edition. If you're on Bedrock and something looks off visually (menu icons especially), that's expected — the custom textures are primarily a Java-side feature.
