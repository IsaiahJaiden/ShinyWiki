# Crates & Keys

ShinyVale has five crate tiers, each with better loot than the last:

| Tier | Notes |
|---|---|
| **Common** | The easiest to come by |
| **Gold** | A step up |
| **Prime** | Solid mid-tier loot |
| **Amethyst** | High tier |
| **Crimson** | The top tier |

!!! info "Not pay-to-win"
    ShinyVale's own signage at the crate area is explicit about this: crates are not, and will never be, a pay-to-win system.

## Opening a crate

```
/warp crates
```

This takes you straight to the crate area at spawn, where each tier has its own dedicated station. Interact with the block for the tier matching the key you're holding to open it.

## Shards

Shards are a secondary currency, separate from your regular money balance, used specifically to buy crate keys and related items through the shop. You'll pick shards up from the same places keys drop — calendar days, voting rewards, and normal play.

```
/convert
```

Opens a menu for converting between currencies if you need to move value between shards and other balances.
