# Contact Staff

## Discord

The **[ShinyVale Discord](https://discord.gg/G74PkPv2XQ)** is the main hub for staff contact, announcements, and the wider community — it's also bridged with in-game chat, so a lot of conversation happens across both at once.

## In-game

```
/discord
```

Shows the Discord invite link directly in-game if you need it while playing.

## What to reach out about

- Reporting a player — see [Reporting a Player](reporting.md) first, it covers what to include
- Bugs and glitches
- Questions about a rule
- General help getting started
