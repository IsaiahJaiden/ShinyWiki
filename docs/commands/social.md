# Social Commands

## Messaging

| Command | Aliases | Description |
|---|---|---|
| `/msg <player> <message>` | `/w`, `/tell`, `/pm` | Send a private message |
| `/r <message>` | `/reply` | Reply to your last private message |
| `/afk` | — | Toggle AFK status |

## Teams

| Command | Description |
|---|---|
| `/teams`, `/team` | Open the teams menu |
| `/teamtoggle` | Toggle a team setting |

## Trading

Trade directly with another player, item for item, with a confirmation screen on both sides before anything changes hands — no command needed, this is initiated in-world.

## Cosmetic poses

A handful of sit/lay commands for hanging out:

<div class="sv-cmd-strip" markdown>
`/sit` `/lay` `/layback` `/bellyflop` `/spin` `/crawl`
</div>

## Voice chat

ShinyVale supports proximity voice chat — talk to nearby players naturally as you play. Check your client's voice chat settings/keybind after joining to get set up.
