# Voting Commands

See [Voting Rewards](../features/voting.md) for what you actually earn.

| Command | Aliases | Description |
|---|---|---|
| `/vote` | — | See the vote site list and links |
| `/votetotal` | `/vtotal` | Check your total vote count |
| `/votenext` | `/vnext` | See when you can next vote |
| `/votelast` | `/vlast` | See when you last voted |
| `/votetop` | `/vtop` | View the top voters |
| `/votebest` | `/vbest` | View your best vote totals |
| `/votestreak` | `/vstreak` | View your current and best voting streaks |
| `/votetoday` | `/vtoday` | See who's voted today |
| `/votehelp` | `/vhelp` | List voting commands in-game |
