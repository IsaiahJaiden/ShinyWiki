# Command Overview

Every command here is something a normal player can use right now — nothing staff-only made it onto this list. Pick a category below for the full breakdown, or use the table for a quick lookup.

## Most useful commands

| Command | Description |
|---|---|
| `/spawn` | Return to spawn |
| `/rtp` | Teleport somewhere random |
| `/claim` | Claim the land around you |
| `/shop` | Open the server shop |
| `/sell` | Sell what you're holding |
| `/warp <name>` | Teleport to a server warp |
| `/tpa <player>` | Request to teleport to a player |
| `/duel <player>` | Challenge someone to a duel |
| `/bounty <player> <amount>` | Put a bounty on someone |
| `/vote` | Vote for the server |
| `/calendar` | Claim today's calendar reward |
| `/rules` | Read the server rules |
