# Command Overview

Every command on this page is one a normal player can actually use right now. Staff-only commands aren't listed.

!!! tip "Looking for something specific?"
    Use the search box at the top of the page — searching `claim`, `home`, `sell`, or `duel` will jump you straight to the right section.

## Most used

| Command | Description |
|---|---|
| `/rtp` | Teleport somewhere random — the fastest way to find land |
| `/claim` | Claim the land you're standing on |
| `/sethome` · `/home` | Set and return to your home |
| `/shop` | Open the server shop |
| `/sell` | Sell items from a menu |
| `/warp <name>` | Travel to a server warp |
| `/spawn` | Return to spawn |
| `/tpa <player>` | Ask to teleport to a player |
| `/settings` | Your personal preferences menu |
| `/calendar` | Claim today's free reward |
| `/vote` | Vote for the server for rewards |
| `/rules` | Read the server rules |

## Claims

| Command | Description |
|---|---|
| `/claim [radius]` | Claim land around you |
| `/claim settings` | Open the settings menu for a claim |
| `/claim merge <claim-1> <claim-2>` | Merge two of your claims into one |
| `/claim addchunk <name>` | Add a chunk to an existing claim |
| `/claim delchunk <name> <chunk>` | Remove a chunk from a claim |
| `/claim add <player>` | Trust a player on your claim |
| `/claim remove <player>` | Remove a trusted player |
| `/claim members [name]` | List trusted members |
| `/claim ban <player>` | Ban a player from your claim |
| `/claim unban <player>` | Unban a player |
| `/claim bans [name]` | List banned players |
| `/claim kick <player>` | Remove a player from your claim now |
| `/claim setname <old> <new>` | Rename a claim |
| `/claim setdesc <name> <text>` | Set a claim description |
| `/claim setspawn` | Set where `/claim tp` lands |
| `/claim tp <name>` | Teleport to one of your claims |
| `/claim list` | List all your claims |
| `/claim map` · `/claim automap` | Show a map of nearby claims |
| `/claim see [player]` | Check whose claim you're standing in |
| `/claim fly` · `/claim autofly` | Toggle flight inside your own claim |
| `/claim chat <name>` | Talk in claim-local chat |
| `/claim main <name>` | Set your main claim |
| `/claim owner <name> <player>` | Transfer ownership |
| `/claim sell <name> <price>` | List a claim for sale |
| `/claim buy` | Buy a listed claim |
| `/claim cancel <name>` | Cancel a claim sale |
| `/claims` | Browse the claims menu |
| `/unclaim [name]` | Remove a claim |

Aliases: `/territory` · `/territories` · `/unterritory`. Full guide: **[Claims](../gameplay/claims.md)**
