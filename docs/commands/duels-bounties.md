# Duel & Bounty Commands

See the [Duels & PvP](../gameplay/duels.md) and [Bounties](../gameplay/bounties.md) guides for a full walkthrough.

## Duels

| Command | Aliases | Description |
|---|---|---|
| `/duel <player>` | `/1v1` | Challenge a player to a duel |
| `/queue` | `/q` | Join the duel matchmaking queue |
| `/kit` | `/dkit` | Open your kits |
| `/kit edit <kitname>` | — | Customize a kit |
| `/kit reset <kitname>` | — | Reset a kit to default |
| `/party` | `/p`, `/duelparty`, `/dp` | Manage a duel party |
| `/spectate` | `/spec` | Spectate an ongoing match |
| `/duel stats` | `/duels` | View your duel rating and match history |

## Bounties

| Command | Aliases | Description |
|---|---|---|
| `/bounty <player> <amount>` | — | Place or add to a bounty |
| `/bounty <player>` | — | Check a player's current bounty |
| `/bountytoggle` | — | Toggle bounty notifications |
