# Getting Started

Welcome to ShinyVale! Here's the fastest path from "just joined" to actually playing.

## 1. Accept the resource pack

You'll be prompted to download ShinyVale's resource pack the moment you connect — accept it. It's required to play properly. Trouble with it? See [Resource Pack](../features/resource-pack.md).

## 2. Read the rules

Quick, but worth doing:

```
/rules
```

## 3. Leave spawn and find land

Spawn is a hub, not where you build. Get out into the world with:

```
/rtp
```

This drops you somewhere random — the fastest way to find fresh, unclaimed land.

## 4. Protect your base

Found a spot? Claim it before you start building:

```
/claim
```

Full guide: [Claims](../gameplay/claims.md).

## 5. Get on your feet economically

Kill some mobs, gather some resources, then head to the shop to turn them into starting cash:

```
/shop
/sell
```

Full guide: [Economy & Shops](../gameplay/economy.md).

## 6. Explore what's around spawn

Spawn has warps to most of the server's other systems:

```
/warp shop
/warp crates
/warp duels
/warp auction
```

## 7. Set a home so you can get back easily

```
/sethome
```

Wherever you end up building, `/home` gets you straight back.

## 8. Check out the calendar

There's a free reward waiting for you right now:

```
/calendar
```

Full guide: [Calendar & Rewards](../features/calendar.md).

## 9. Vote for the server

Takes ten seconds and pays out real rewards:

```
/vote
```

Full guide: [Voting Rewards](../features/voting.md).

## 10. Find your people

Trade with other players at the [auction house](../gameplay/auctions.md), visit builds through [player warps](../gameplay/player-warps.md), or drop into [Discord](https://discord.gg/G74PkPv2XQ) to say hi.
