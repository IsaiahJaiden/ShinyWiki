# Server Information

## Worlds

| World | What it's for |
|---|---|
| **Spawn** | The hub — shops, warps, crates, duels, and the auction house |
| **ShinyWorld** | The main survival overworld |
| **ShinyNether** | The nether dimension |
| **ShinyEnd** | The end dimension |
| **AfkZone** | A dedicated, safe area for going AFK |

## Cross-platform play

ShinyVale supports both Java and Bedrock Edition players on the same server — see [Bedrock & Crossplay](../features/bedrock.md) if you're joining from console, mobile, or Bedrock on PC.

## Version support

ShinyVale supports connecting from a range of recent Minecraft versions, not just the latest one.
